# MajorityIQ polls — released, leads, internal intake

## Public released polls

| File | Purpose |
|------|---------|
| `data/polls/released.json` | Verified public horse-race polls (committed) |
| `data/polls/leads.json` | RSS leads to verify (no auto-toplines) |
| `data/polling/latest.json` | Legacy per-district summary (generated by builder) |

Refresh (weekday, via `scripts/update-daily-majorityiq.sh`):

```bash
./scripts/update-released-polls.sh
```

1. `fetch_poll_leads.py` — Google News + Berkeley IGS + PPIC RSS → `leads.json`
2. `build_polling_latest.py` — sync `latest.json` from `released.json`

## Entering a campaign poll (private)

1. Sign in at `/admin/login`
2. Open **Internal poll intake**: `/admin/majorityiq/polls-admin`
3. Enter aggregate toplines only (no respondent rows, no voter file)
4. Save — desk merges via `/admin/majorityiq/api/polls/internal` (session + CSRF)

Optional CSV import (same page): columns documented on the form.

To publish publicly: verify source, add a row to `data/polls/released.json`, run `update-released-polls.sh`, commit JSON.

## Threat Index poll factor

- Window: `gap_recent_days` (default 90)
- Newest qualifying poll per district
- Independent: full weight; campaign / party / IE: ×0.5 + partisan flag
- Internal D1 polls: merged at runtime in the authenticated app (not in build artifact)
