# Beachhead map geometries

| File | Description |
|------|-------------|
| `beachhead-districts.geojson` | Simplified 2020-cycle Assembly shapes for portfolio beachheads only (AD-7, 27, 36, 47, 58, 74). ~11 KB. |

**Source:** [California State Assembly Districts Map 2020](https://gis.data.ca.gov/datasets/California::california-state-assembly-districts-map-2020) (CA Open Data). Geometries decimated for static SVG rendering — not for legal boundary work.

Regenerate from the full statewide GeoJSON with the extract script in repo history or re-run a local simplify step if boundaries change after redistricting.
