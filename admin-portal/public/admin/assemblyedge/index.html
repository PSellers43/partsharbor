    Methodology & trust

    What MajorityIQ measures, where production data comes from, and what this prototype is not.

    Sources in this build

    • CAL-ACCESS — candidate & IE filings, late contributions (static JSON; manual scripts/update-calaccess.sh)
    • Threat Index + News + Rival + Alerts — computed from CAL-ACCESS + Google News RSS + curated polls (scripts/update-intel.sh)
    • 2024 lean — CA SOS Statement of Vote Assembly totals (data/election-history/official/asm-2024-general-sov.json)
    • SWDB — precinct Assembly margins (2022/2024, addist-filtered), ABEV mail-return baselines (update-election-history.sh / update-abev.sh)
    • CA SOS ROR — registration by Assembly district (update-demography.sh)
    • CA SOS BSR — county mail ballot status XLSX (county rows in ABEV; not AD totals)
    • Public X digest — paid X API + bundled fallback; keyword tone estimate (not polling)
    • Curated polls — hand-maintained data/polling/latest.json with explicit gap rows
    • Ads tab — unavailable in this build until wired (no silent placeholders)

    Panels show as-of stamps in Pacific Time. Missing bundles render explicit unavailable states — no fictional numbers. See CALACCESS.md.

    Update cadence

    • All layers are manual refresh today — run scripts/update-daily-majorityiq.sh or individual update scripts on a schedule you control.
    • CAL-ACCESS: weekday SOS ZIP export
    • Intel (TI/news/rival): after CAL-ACCESS + polling JSON
    • Monday Brief: printable rollup from loaded bundles

    Threat Index factors

    • Money velocity — 7-day late contributions plus all 7-day IE dollars (both sides) in FPPC 90-day window (CAL-ACCESS S497/S496), ranked across beachheads
    • IE pressure — 7-day IE with direction-aware anti-R vs pro-R totals
    • Ad surge — excluded (not in composite)
    • Narrative heat — headline count in last 7 days (Google News RSS at build time)
    • Poll movement — included only when a curated public poll is inside the gap window
    • Focus map — EST heuristic (40% TI + 35% money + 25% poll gap); drill adds addist-filtered SWDB precinct margins and ACS + SOS registration

    Click any factor on a district Threat Index tab for the methodology drawer.

    Decision chips

    Alerts surface a decision type — Consider spend / Hold & monitor / Message check — as operator guidance taxonomy. They are not automated orders, win probabilities, or legal advice. CM Board extends this with Field surge and a persisted decision log.
