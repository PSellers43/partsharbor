PartsHarbor Channel Ops Pack
============================
Paste-ready listing snippets and a placement checklist for sellers who ship
passenger / off-highway motor vehicle parts to California buyers online.

NOT legal advice. NOT a compliance guarantee. You decide whether a warning
applies to your products. PartsHarbor only supplies implementation files.

Included
--------
1. ebay-listing.html — sample HTML you can adapt for eBay item descriptions
2. amazon-warning.txt — notes for Amazon WARNING / hyperlink style fields
3. shopify-woocommerce-snippet.html — simple WARNING block for product pages
4. placement-checklist.md — where the WARNING should appear before purchase
5. catalog-blurb.txt — short catalog / feed style blurb

How this relates to the Shop Kit
--------------------------------
Shop Kit ($29) = print-focused (counter sign, labels, manufacturer notice) plus starter listing notes.
Channel Ops (~$19 add-on) = expanded internet / marketplace implementation pack.
Shop Kit Complete ($49) = Shop Kit + Channel Ops in one download.
