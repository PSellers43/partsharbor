# Internet / marketplace placement checklist
PartsHarbor Channel Ops · Not legal advice

Before a California buyer can complete purchase, confirm:
- [ ] A clear **WARNING** is visible on the product detail / listing page (not only after checkout).
- [ ] The warning uses the published tailored motor-vehicle-parts safe-harbor wording and official URL path you intend to rely on.
- [ ] Mobile layout still shows the warning without hiding it behind tabs the buyer never opens.
- [ ] Marketplace-specific fields (eBay description HTML, Amazon warning/hyperlink fields) are filled — theme/footer-only notices are not a substitute for listing-level methods.
- [ ] If you also have a physical counter in CA, treat **posted sign** and **internet listing** as separate channels.
