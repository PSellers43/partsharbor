CA parts seller — warning channels checklist

PartsHarbor · Free one-pager · Not legal advice

Use this page in the browser or for a clean one-page worksheet.

Use this to see which implementation channels you may need if you sell passenger or off-highway motor vehicle parts into California. This does not decide whether any specific part requires a warning.

1. Brick-and-mortar / counter or rack

  • Do customers see parts on a counter, rack, or showroom floor in California?
  • If yes: do you have a print-ready posted 5×5 (or other published posted method) with the tailored motor-vehicle-parts safe-harbor text?
  • If other consumer signage at the location is bilingual, check whether you also need Spanish materials.

PartsHarbor file help: Shop Kit counter sign PDF + EN/ES labels.

2. Online / marketplace listings

  • Do you sell on eBay, Amazon, Shopify, or your own site to California buyers?
  • If yes: posted store signs alone usually do not cover internet sales — listings need a clear WARNING path before purchase (published internet methods under 27 CCR § 25602).
  • Paste-ready HTML / notes ready for eBay, Amazon, and your product page?

PartsHarbor file help: Channel Ops / Shop Kit Complete (listing snippets + placement checklist). Learn about Channel Ops

3. Product labels / packaging

  • Do you apply on-product or shelf labels for CA-bound inventory?
  • Print sheets sized for common Avery layouts?

PartsHarbor file help: Shop Kit label PDFs.

4. Supplier → retailer notice trail

  • Do you supply parts to other retailers who sell in / into CA?
  • Do you have a simple notice PDF + acknowledgment / send log workflow (ops paperwork, not a legal opinion)?

PartsHarbor file help: manufacturer→retailer notice template in the Shop Kit.

5. Scope sanity check (educational)

This kit path is for passenger or off-highway motor vehicle parts. Site scope notes exclude tires, packaged service chemicals, asbestos parts, carpeting, upholstery, textiles, or fabrics (see 27 CCR § 25607.50(b) as cited on partsharbor.biz). Confirm against current OEHHA / CCR text; this checklist is not a determination.
